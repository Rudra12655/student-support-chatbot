# Courses & Programs

## Full-Stack Web Development Bootcamp
- Duration: 16 weeks (part-time evening & weekend friendly).
- Prerequisites: Basic computer literacy; no prior coding experience required.
- Core Topics: HTML5, CSS3, JavaScript (ES6+), React, Node.js, REST APIs, SQL/NoSQL databases, Git, and deployment.
- Capstone: Build and deploy at least 2 full-stack projects with code reviews.

## Data Science & Applied AI Track
- Duration: 20 weeks.
- Prerequisites: Basic familiarity with high-school math or spreadsheets; Python basics are covered in Week 1.
- Core Topics: Python, NumPy, pandas, SQL, data visualization, statistics, machine learning, embeddings/vector search, and RAG basics.
- Capstone: End-to-end data/AI application with evaluation notes.

## Switching Courses & Refunds
- Course switch requests are allowed within the first 10 calendar days of batch start, subject to seat availability.
- Refund and deferral policies are handled by Student Admissions; if you need an exception or invoice copy, escalate to human support.
